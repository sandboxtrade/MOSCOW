# MOSCOW 0.3.17 — первая комната

Изменения:
- Артикулированные руки и ноги: шаг, движение плеч, дыхание, моргание и разговорные жесты.
- Выбор проводника, телефона или рабочего места запускает подход по проходу вокруг стола. Действие открывается после прибытия. Новый выбор отменяет прошлый маршрут.
- Статичный фон мемоизирован отдельно от персонажей; порядок персонажей зависит от глубины.
- Дождь ограничен рамой окна, редкие огни проезжающих машин, пар от кружки.
- Свет включается и выключается; фоновую анимацию можно остановить. Учитывается prefers-reduced-motion.
- Камера больше не качается за курсором. Рисунок и области нажатия используют один контейнер 360×540.
- Переработан журнальный стол, добавлены нижняя полка и часы на тумбе.

Проверка: npm run check. Проверки UI выполняются с подменой ответов API: подход к телефону, открытие покупки, диалог, лампа, reduced motion, размеры 375/430/1440. Реальная покупка и удалённый деплой в этой итерации не выполнялись.

Запуск: npm install, затем npm run dev:web. Обновление интерфейса — заменить файлы проекта и выполнить привычный Pages deploy. Миграции БД не нужны.
