# MOSCOW — старт для нового чата

Актуальная база: **MOSCOW-v0.3.14-deploy-safe-live-room.zip**.

Использовать только её как исходник.

## Главное изменение

Это прямое продолжение `v0.3.12-live-faux3d-room`. В `v0.3.14` я не откатывал сцену назад в PNG, а наоборот усилил live-подход: лучше проработал комнату, наполнил её деталями, усилил свет/глубину и перерисовал персонажей так, чтобы они были ближе к игровым, а не к грубым временным заглушкам.

Теперь внутри live-сцены есть:

- более плотная и глубокая стартовая комната
- улучшенное окно, занавески и ночной город
- трубы, постеры, полка, фото, лампа, крючок с одеждой
- улучшенные мебельные и кухонные блоки
- более читаемый свет и глубина сцены
- переработанный игрок
- переработанный проводник
- живые idle/talking состояния персонажей
- всё ещё без PNG-фона комнаты и без PNG-персонажей

UI MOSCOW не копировать с других проектов. Другую игру использовать только как референс по ощущению живого мира, не по интерфейсу.

Backend, D1, wallet, purchase flow, phone ownership, dialogue, quests, GitHub/Cloudflare auto-deploy сохранены.

Старые миграции `0001–0003` не менять. Следующая БД-миграция — только `0004_...sql`, если реально потребуется.

Текущий приоритет: открыть `v0.3.14` на телефоне и уже от реального скрина править масштаб/композицию/читаемость сцены. Город и двор пока не делать.


Важно: при проверке деплоя на экране должна быть видна метка `v0.3.14 · LIVE`. Если её нет, открыта старая версия.
