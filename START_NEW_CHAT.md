# Обновление 0.3.17

Актуальная версия: 0.3.17. Первая комната и анимации переработаны; подробности в docs/ROOM_ANIMATION.md. Ниже сохранены предыдущие сведения.

# MOSCOW — старт для нового чата

Актуальная база: **MOSCOW-v0.3.16-live-pixel-room.zip**.

Использовать только её как исходник.

## Важное

`v0.3.16` — это новый визуальный проход комнаты. Мы отказались от гладкого мультяшного faux-3D вида `v0.3.14` и перестроили комнату как live pixel-art сцену через React + inline SVG + CSS. Старый PNG-фон комнаты в рантайме не используется.

Композиция теперь ближе к утверждённому референсу квартиры: окно/город ночью, кровать слева, рабочее место справа, холодильник/кухня справа, ковёр и журнальный стол в центре. Игрок и проводник тоже перерисованы как blocky pixel characters.

UI MOSCOW остаётся отдельным и не копируется с другой игры.

Backend/D1 не менять без необходимости. Старые миграции `0001–0003` не переписывать. Следующее изменение БД — только `0004_...sql`, если реально потребуется.

Проверочный маркер в комнате: `v0.3.16 · PIXEL ROOM`.

Следующий приоритет: смотреть именно этот билд на телефоне и править масштаб/детализацию комнаты и персонажей по реальному скриншоту. Город и двор пока не делать.

В `v0.3.16` дополнительно усилены городской вид, пиксельные материалы, ковёр, постель, мелкий декор и детали персонажей. Стартовый экран избавлен от технического описания. Сцена по-прежнему работает без PNG-фона; backend/D1 не менялись. Не возвращаться к `v0.3.15` как к рабочей базе после принятия нового архива.
