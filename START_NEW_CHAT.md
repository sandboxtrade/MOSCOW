# Стартовое сообщение для нового чата

Продолжаем разработку игры **MOSCOW**.

Актуальная база проекта — архив **MOSCOW-v0.3.9-room-ambient-ui-pass.zip**. Используй только его как исходник и не возвращайся к старым версиям.

## Что уже есть

- React + Vite frontend.
- Cloudflare Worker backend.
- D1 database `moscow-city-db`.
- Durable Object `EconomyCoordinator`.
- Аккаунты FREE/FUNDED.
- Стартовый баланс 200 000 ₽G, он NON_WITHDRAWABLE.
- TEST SOL deposit/withdraw.
- SOL ↔ ₽G exchange.
- Ledger, transactions, idempotency.
- Player progress, catalog, inventory, purchases.
- Покупка `starter_phone` за 15 000 ₽G.
- Автодеплой GitHub Pages и Cloudflare уже настроен.
- GitHub: `sandboxtrade/MOSCOW`, ветка `main`.

## Что уже сделано по комнате

- Комната уже собрана как отдельная игровая сцена.
- Есть HUD, objective chip, раскрывающийся блок задач, диалог, магазин телефона и экран телефона.
- Добавлены лёгкие ambient-эффекты: свечение окна, лёгкое мерцание города, мягкое освещение у лампы/рабочего места, минимальное движение для "живости" сцены.
- Временные пиксельные человечки пока оставлены как заглушки, но их позиции уже выровнены лучше.
- Город/двор пока специально НЕ продолжаем. Приоритет — довести текущую комнату и интерфейс.

## Как теперь работаем

Работаем вертикальными кусками: **визуал → взаимодействие → минимальный backend → проверка**.

Не присылай мне огромные куски кода для ручного копирования. Правь проект целиком и возвращай готовый ZIP с аккуратной структурой. Не добавляй `node_modules`, `dist`, `.wrangler` и прочий генерируемый мусор.

Старые миграции `0001`–`0003` не переписывать. Следующее изменение БД — только новой миграцией `0004_...sql`, если она реально понадобится.
